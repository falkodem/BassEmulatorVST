# Эксплуатация BassEmulatorVST в Reaper

## Частота дискретизации

Установи для проекта Reaper и аудиоустройства **44 100 Гц (44,1 кГц)** до записи и обработки. Текущая модель PESTO экспортирована для этой частоты: она получает блоки по 441 сэмплу (10 мс). Плагин не пересчитывает входной сигнал на другую частоту. При запуске проекта на другой частоте определяемая высота ноты будет неверной.

Перед записью проверь фактическую частоту проекта и аудиоустройства в Reaper. Если используешь другой проект или аудиоустройство, снова проверь 44,1 кГц перед включением плагина.

## Использование

1. Подключи гитару и выбери монофонический вход дорожки.
2. Добавь `BassEmulatorVST` в эффекты дорожки.
3. Играй по одной ноте. Детектор рассчитан на гитарный диапазон E2–E4; синтезированный бас звучит на октаву ниже.
4. Настрой соотношение сухого и басового сигнала регулятором `Dry/Wet` в интерфейсе плагина.

До первого уверенно определённого тона плагин пропускает сухой сигнал. Для записи готового звука используй обычный рендер или запись выхода дорожки в Reaper.

## Сборка и установка

Три готовых ONNX-экспорта и команды сборки каждого варианта описаны в
[README.md](../README.md#сборка-с-одной-из-трёх-pesto-моделей). Модель
выбирается при конфигурации CMake через `PESTO_ONNX_PATH`; переключателя в
интерфейсе плагина пока нет. После сборки закрой Reaper перед заменой
установленного VST3, затем открой проект и проверь частоту дискретизации.
